
# Network Scanning

Network scanning is used to identify hosts, open ports, and available network services.

A port scan may generate repeated connection attempts to multiple ports on a host. However, legitimate administrators and security tools can also perform scanning.

Investigators should examine the source IP, destination IP, destination ports, timestamps, connection patterns, and surrounding network activity before deciding whether the activity is malicious.

A port-scan alert alone does not prove that a system was compromised.
